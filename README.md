# Фото для DV Lottery — личное локальное приложение

Готовит фотографию для заявки на Diversity Visa Program: находит лицо, подбирает кадр,
заменяет фон на белый, проверяет геометрию и технические параметры файла и сохраняет JPEG 600 × 600.

Всё работает **на этом компьютере**: страница открывается в браузере с адреса `http://127.0.0.1:…`,
распознавание лица и сегментация выполняются в браузере моделями MediaPipe из папки `public/models`.
Фотография никуда не отправляется.

## Запуск

### Самый простой способ (Windows)

Дважды щёлкните **`start.bat`**. При первом запуске он установит зависимости и подготовит модели (нужен интернет,
один раз). Приложение собирается при каждом запуске (пара секунд), поэтому правки исходников подхватываются сами.
Затем откроется браузер. Остановить — закрыть окно консоли или `Ctrl+C`.

### Вручную

Нужен Node.js 20+ (проверено на 24.18).

```bash
npm install          # зависимости (однократно)
npm run setup        # копирует WebAssembly MediaPipe и проверяет/скачивает модели (однократно)
npm run build        # сборка в dist/
npm start            # сервер на 127.0.0.1:5178 и открытие браузера
```

После изменения исходников снова выполните `npm run build`. Порт можно сменить: `PORT=6000 npm start`
(если 5178 занят, сервер сам возьмёт следующий свободный). `npm start -- --no-open` — не открывать браузер.

## Как пользоваться

1. «Выбрать фото» (или перетащить файл): JPEG, PNG или WebP.
2. «Автоматическая обработка» — кадр и белый фон подбираются сами; «Ручная настройка» — кадр выставляете вы.
3. В редакторе: перетаскивание мышью — сдвиг, колесо — масштаб, ползунки «Масштаб» и «Поворот»
   (значение можно ввести числом), рамку на исходном фото можно двигать и тянуть за углы,
   кнопки «Авто-кадр», «Центрировать лицо», «Выровнять по глазам». Линии «Макушка», «Глаза»,
   «Подбородок» перетаскиваются за ярлычки — если автоматика ошиблась, поправьте их.
4. Вкладка «Фон»: включение замены, белый или почти белый, «Граница маски», кисти «Вернуть человеку» /
   «Убрать в фон». «Сравнить до/после» показывает результат и, через разделитель, исходный снимок целиком («Оригинал»)
   или тот же кадр без обработки («Кадр» — удобно проверять края маски).
5. Вкладка «Цвет»: умеренные яркость, контраст, тёплый/холодный оттенок, автобаланс белого.
6. `Ctrl+Z` / `Ctrl+Y` — отмена и повтор, «Сбросить» — вернуться к исходному варианту.
7. «Подтвердить результат» → проверка файла → «Сохранить JPEG». В Chrome/Edge откроется окно выбора папки,
   после записи файл читается с диска и проверяется ещё раз.

## Требования, которые проверяются

Источники (проверено 18.10.2026):
[Photo Requirements](https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos.html),
[Digital Image Requirements](https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos/digital-image-requirements.html),
[Photo Composition Template](https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos/photo-composition-template.html).

| Параметр | Значение |
|---|---|
| Формат | JPEG (проверяется по содержимому файла) |
| Размер | квадрат; для DV — **600 × 600** (общий диапазон для цифровых фото виз 600–1200) |
| Цвет | 24 бита на пиксель, sRGB |
| Размер файла | ≤ 240 кБ (берётся 240 000 байт — строже) |
| Сжатие | не сильнее 20:1 (для 600 × 600 это файл ≥ 54 000 байт) |
| Голова | от макушки (с волосами) до подбородка — 50–69 % высоты |
| Глаза | 56–69 % высоты от нижнего края |

## Приватность и сеть

- Сервер (`server.mjs`) слушает только `127.0.0.1`, отвечает только на запросы с локальным именем хоста.
- Страница получает заголовок Content-Security-Policy с `connect-src 'self'`: браузер блокирует любые запросы
  на другие адреса.
- В библиотеку MediaPipe встроена отправка статистики использования на `odml.pa.googleapis.com`; при сборке
  этот адрес заменяется на `about:blank`, запрос не уходит в сеть.
- Интернет нужен только при установке: `npm install` и однократная загрузка двух моделей
  (с проверкой SHA-256) скриптом `npm run setup`.
- Ничего не сохраняется, кроме файла, который вы сами сохраните. Исходный файл не изменяется.

## Устройство

Код разложен по папкам по смыслу; интерфейс лежит рядом со своей логикой.

| Папка | Что внутри |
|---|---|
| `src/app/` | точка входа, `App.tsx` (переключение экранов), стили |
| `src/screens/` | экраны: стартовый, «снимок загружен», редактор (`Workspace.tsx`) |
| `src/photo/` | открытие файла: формат по содержимому, EXIF-ориентация, `usePhoto` (снимок и его анализ) |
| `src/face/` | модели MediaPipe: поиск лица и ориентиров, маски, поиск макушки |
| `src/processing/` | расчёт итогового кадра: Web Worker (`engine.worker.ts`), конвейер, маска, цвет, очередь расчётов |
| `src/editor/` | редактор кадра, рамка на исходнике, история отмены, состояние правок, панели «Кадр», «Фон», «Цвет» |
| `src/checks/` | нормы Госдепартамента и проверки кадра, их отображение |
| `src/export/` | кодирование JPEG в пределах 240 кБ, проверка файла, сохранение |
| `src/shared/` | геометрия кадра, ползунок с полем ввода |

- Экран редактора монтируется заново для каждого запуска обработки, поэтому история, инструменты и экспорт всегда
  начинаются с чистого листа. История отмены (`editor/useHistory.ts`) — чистые функции, покрыты тестами.
- Итоговое изображение и анализ лица считаются в Web Worker, поэтому интерфейс не замирает. Пока кадр тянут мышью,
  показывается быстрый предпросмотр со сдвинутой прежней маской; полный расчёт — после отпускания кнопки или паузы.
- Если Worker не запустился (в консоли браузера будет предупреждение; возможно в `npm run dev`), расчёт идёт
  в основном потоке — работает так же, но после отпускания мыши страница на долю секунды замирает.

## Ограничения

- Приложение не гарантирует принятие фото — решение принимает Госдепартамент США.
- Очки, головной убор, давность снимка, взгляд в камеру, ретушь, одежда проверяются только вами
  (в списке «Проверьте сами»).
- Выражение лица, открытые глаза, поворот головы оцениваются моделью приблизительно. Их нельзя исправить
  кадрированием — в таких случаях приложение советует переснять.
- Модель сегментации работает с разрешением 256 × 256; края уточняются цветным управляемым фильтром. На сложном
  фоне тонкие пряди могут обрабатываться неидеально — подправьте маску кистью или ползунком, либо переснимите фото
  на светлой однотонной стене и выключите замену фона.
- Если модель не нашла волосы над лбом, макушка ставится приблизительно и проверка высоты головы получает статус
  «Не удалось проверить автоматически», пока вы не перетащите линию «Макушка».
